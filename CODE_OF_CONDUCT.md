# Code of Conduct

This project adopts the [Contributor Covenant](https://www.contributor-covenant.org/),
version 2.1.

In short: be respectful, be constructive, and assume good faith. Harassment and
abusive behavior are not tolerated.

Report concerns to the maintainers (see [MAINTAINERS.md](./MAINTAINERS.md)).
The full text of the Contributor Covenant v2.1 is available at
https://www.contributor-covenant.org/version/2/1/code_of_conduct/.
