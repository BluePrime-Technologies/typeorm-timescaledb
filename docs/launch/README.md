## Messaging guardrails

Keep the launch message honest and pre-1.0 appropriate:

- Say the package is TypeORM-first and TimescaleDB-focused.
- Say it generates reviewable migrations.
- Say it avoids global TypeORM mutation.
- Say it supports NestJS and multiple DataSources.
- Say it has production-minded safety guidance.
- Do not claim full TimescaleDB feature coverage.
- Do not claim complete automatic schema diffing.
- Do not claim destructive rollback support.
- Do not promise exact release dates.
- Invite feedback from TypeORM, NestJS, and TimescaleDB users.

## Primary launch message

`typeorm-timescaledb` brings TimescaleDB workflows into TypeORM with reviewable
migrations, NestJS support, typed query helpers, and a production-minded safety
model — without globally mutating TypeORM.
